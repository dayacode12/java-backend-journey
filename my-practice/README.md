# My Practice

This folder is your personal DSA sandbox.

Use it for first attempts, rough code, debugging experiments, and alternate approaches. Keep polished final solutions in `leetcode-solutions/`.

## Suggested Flow

```text
1. Pick a problem from docs/dsa-roadmap.md
2. Create a Java file in the matching folder here
3. Try solving without looking at the final solution
4. Add print/debug statements freely
5. Once it works, rewrite the clean version in leetcode-solutions/
```

## Keep It Simple

```text
my-practice/
  phase1-logic-foundations/
    strings-arrays/
      ReverseStringTry1.java
```

Create new folders only when you start practicing that topic.

## Naming Convention

Use simple names while practicing:

```text
ReverseStringTry1.java
ReverseStringTry2.java
TwoSumBruteForce.java
TwoSumHashMap.java
```

The goal here is learning, not perfection.
